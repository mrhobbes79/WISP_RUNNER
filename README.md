# 🗼 WISP Runner 2 — Build the Network. Conquer the City.

An isometric strategy-action browser game where you play as a WISP technician installing wireless antennas on rooftops across 10 real cities in Latin America and the US.

Built as a love letter to the fixed wireless industry — for the WISPA, WISPMX & ABRINT communities.

## 🎮 Play Now

Open `wisp_runner_2.html` in any modern browser. That's it — no install, no server, no dependencies.

## ✨ Features

| Feature | Details |
|---------|---------|
| 🏙️ **10 Real Cities** | Monterrey, CDMX, Guadalajara, Rio de Janeiro, São Paulo, Dallas, Bogotá, Buenos Aires, Miami + Grand Finale |
| 📡 **30 Levels** | Progressive difficulty with unique maps per city |
| 🎯 **Antenna Alignment** | Azimuth/elevation mini-game with real RF concepts (dBm, signal strength) |
| 🤝 **Negotiation System** | Recover lost clients from competitors via timing-based bidding |
| 🌧️ **Dynamic Weather** | Rain, wind, lightning, heat waves affect gameplay |
| 🚐 **Competitors** | Cable vans, fiber crews, and signal jammers race for rooftops |
| 📈 **Career Progression** | Técnico Jr → Senior → Ingeniero RF → Dueño de WISP |
| 🏔️ **City Landmarks** | Cerro de la Silla, Faro del Comercio, Cristo Redentor, Obelisco, Reunion Tower... |
| 🌐 **Trilingual** | English / Español / Português |
| 🔊 **Synthesized Audio** | Web Audio API — no external sound files |
| 🎯 **Easter Eggs** | Type "WISPA" or "MIMOSA" for special modes |
| 💾 **Persistent Save** | LocalStorage — progress survives browser refresh |
Arrow Keys Move technician
Space Climb / Lock antenna / Interact
Q / E Rotate camera view
H Show instructions
P / ESC Pause (or descend from rooftop)
L Change language (EN/ES/PT)

## 🏗️ Tech Stack

- **Single HTML file** (~2,900 lines, <200KB)
- HTML5 Canvas + pure JavaScript (ES6+)
- Web Audio API (all sounds synthesized)
- Google Fonts: Nunito + Space Mono
- Works fully offline (with system font fallback)
